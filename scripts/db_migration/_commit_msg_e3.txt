新增模块:
- quantmind/execution/
  * exit_decision.py: ExitDecision dataclass + ExitReason Literal
  * stop_loss_engine.py: 规则引擎（5 优先级）
    1. stop_loss   - current < stop_loss_price
    2. target_hit  - current >= target_price
    3. trailing_stop - 从持仓期高点回撤 >= 15%（可配）
    4. time_expired - days_held >= holding_period
    5. regime_change - bull→bear 且热门行业（默认关）
  * manager.py: ExecutionManager
    - open_position_from_recommendation: 写 simulated_orders
    - daily_update: 扫 OPEN 订单 → 更新极值 → 评估退出 → 平仓
    - close_position: 计算 PnL + commission + slippage
    - has_open_position / get_open_orders / get_closed_orders
    - parse_holding_horizon: 解析 '21d'/'3m'/63 → int 天数
    - parse_position_size: 解析 '5%'/'轻仓(1-3%)' → 0-1 浮点
