## ⚠ 方向异常 + 证伪（必读，防误读）

**预期** v6 neut IC < v5 的 0.034（"幸存者上界被拿掉"）。**实测** v6 = 0.052–0.057 **高于** v5。
对一次幸存者修复的判定跑，"超预期变好"必须先证伪 artifact，否则等于自欺。

**已做分解诊断（非调参，纯拆解）**：
- 假设：退市票真实暴跌标签 = 可预测崩盘簇，抬高 IC。
- 结果：horizon 内将退市的行仅 **343/700122 = 0.049%**（top-1500 内仅 13 行）；
  剔除这些行后 neut IC：全市场 0.0521→0.0522、top-1500 0.0570→0.0571，**Δ=0.0001**。
- 结论：**IC 升高与退市崩盘簇无关**，假设证伪。

**真实机制（正确解读）**："幸存者抬高回测"针对的是**持仓组合收益**；对**截面排序 IC** 往往相反——
> ⚠ **初版机制（"中小盘 alpha 更强"）已被补1 证伪**，见下方"补1/补2 + 定因诊断"。
> 正确机制 = **评估票池的幸存者选择压低 IC，模型本身 v5≈v6**（Diag B 实锤）。

**已排查的泄漏向量（均干净）**：
- PIT：Alpha158 因果（G1-mini corr=1.0）；35因子/survivors 在 as_of 截面；seasoning=list+120td≤as_of；
  adv20 top-1500=trailing-20td 成交额仅 ≤as_of；log_mktcap=daily_basic@as_of。
- fold：purged+embargo(h=12,emb=20)；decide_direction 仅 val；模型代码 = batch-A 未改（G2 机制复现 v2）。
- net 超额基准：top-1500 口径基准 = 等权 top-1500（流动票），非含崩盘的全市场等权 → +2.75% 干净。

### 定因诊断（继续找因，纯隔离，不调参）
- **Diag A**：用当前 harness 重评 v5 的 ridge_full 预测 → neut IC **0.034** / net **+1.87%** / ICIR 0.64。
  → v5 基线**仍成立、可比**（非 stale）。
- **Diag B**：v6 预测**限制到 v5 的 1373 票**、桶内中性化 → neut IC **0.032**（覆盖 1371 票，142 as_of）。
  → **同票池上 v6 模型 ≈ v5 模型（0.032≈0.034）**。模型/特征/泄漏**无差异**。

**定论（机制实锤）**：IC 抬升（0.034→0.052/0.057）**全部来自评估票池组成**，非模型变好：
- v5 的 1373 = 今日指数成分 = **幸存者选择**：把后来退市/掉队的输家**事前剔除**了 →
  结局分散度被压缩 → 截面排序**更难** → 测得 IC 被**压低**。
- v6 任一 PIT 票池保留完整结局分布（含后来的输家）→ 分散度满 → 测得 IC 更高。
- top500 ≠ v5 不是因为 top500 被抬高，而是 **v5 的 1373 本身被幸存者压低**了。
  Diag B（同票池→同 IC）排除了模型/特征/泄漏 artifact。**+0.057 是诚实票池上的真实可交易读数。**

## 方法论副产物（留给未来）
**"幸存者限制对截面排序 IC 的方向是【压低】、而非抬高。"**
- 直觉"幸存者抬高回测"针对的是**持仓组合收益**（输家被剔，组合看着更好）。
- 但对**截面排序 IC**：幸存者票池把输家事前剔除 → 结局分散度被压缩 → 模型可排的差异变小 →
  测得 IC 反而**被压低**。Diag B 实证：同一模型，幸存者票池 0.032 vs 诚实票池 0.057。
- 推论：任何"在今日指数成分上回测"的因子研究，其截面 IC 是**保守下界**，非乐观上界。
  这是本次幸存者修复的**额外回报**——诚实票池给出的是更高、且可交易的真实 IC。
