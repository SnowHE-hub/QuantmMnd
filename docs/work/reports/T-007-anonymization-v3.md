## 5. 解读与对生产的含义
1. 在这个设置里（T-010 的 LGBM Top-30、7 个因子、保留日期），**LLM 重排相对 LGBM 没有可检测的增益，且不如一条固定的简单因子规则**；
   显式标识的效应在 ±0.05 以内。δ = 0.05 是针对这个排序指标的容忍界限，**尚未与净投资收益对应**。
2. 建议：**生产里继续关闭 LLM 重排**（定时任务的 `--no-llm` 保持不变）。LLM 用于解释和研究报告，不用于决定排名；
   为提升排名去升级或微调 LLM 的理由不足。
3. "简单规则优于 LGBM 的 Top-30 内排序"提示主线 A 的 LGBM 在候选内部的排序很弱（与 T-010 的 IC ≈ 0 一致）。
   这是对 LGBM 的描述，不是对简单规则的检验；要用它，需要另行预登记。
