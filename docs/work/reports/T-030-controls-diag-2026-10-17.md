## N1：种子 0 换成以折为单位

来源：`docs/work/evidence/T-030/p6/n1_foldci_63d.json`，读的是已有的 `data/gpu_v1/preds/xgb_63d_N1shuffle`。块长 13 的区间与 `controls_63d.json` 逐位相同。

9 个外层折里，最后一折（切点 2026-04-30）的 7 个测试 as_of 是 2026-08-04 至 2026-09-15。面板止于 2026-10-09，这些日子的 `y63` 全是缺失，所以没有日 RankIC。折级区间用其余 8 折的折内均值。

8 个折均值：0.0611、0.0427、−0.0033、0.0505、−0.0041、0.0033、0.0168、0.0223。Student-t 95% 区间（自由度 7）是 **[0.0026, 0.0447]**，均值 0.0237，标准误 0.0089。这个区间也不含 0。

块长 13 的区间半宽约 0.0123，折级区间半宽约 0.0211，大约宽 1.7 倍。把抽样单位从日期改成折，种子 0 的结论不变：区间仍在 0 的上方。

因此，单凭“块长 13 短于一折”还不能把种子 0 说成通过。还要看别的打乱种子是不是也这样。若只有种子 0 偏高，才支持“这一次置换在折内粘住了某个因子”。

## N2：1 日收益在 63 日标签里占多少

来源：`docs/work/evidence/T-030/p6/n2_assoc_63d.json`。样本是 63 日折 0 的内层训练日，与 `p6_controls.py` 里训练金丝雀的那一批日期相同。没有重训模型。

`y63` 是 63 个交易日的简单收益。随后 63 个交易日的 `r_cc` 之和与 `log(1+y63)` 的相关是 1.000（1,319,380 行），所以这条对数收益之和就是 63 日标签。

在这批行上：

- 1 日对数收益的方差 / 63 日对数收益的方差 = **0.0208**。独立同分布的基准是 1/63 = 0.0159。
- 用 1 日对数收益线性解释 63 日对数收益的 R² = 0.0161。
- 金丝雀与 `y63` 的日均 Spearman = **0.127**（378 个交易日；有限标签且有下一日收益的行 1,365,677）。截面相关按日计算，gauss-rank 不改变 Spearman。

金丝雀不是噪声：它和 63 日标签的日均秩相关是 0.13。它也只占标签方差的大约 2%。正式特征是 250 个股票列加 26 个市场列，加上金丝雀共 277 列 [代码，`data/gpu_v1/model/v1/features.json`]。要求这一列的 gain 排第 1，等于要求一个约占 2% 方差的未来列压过可以拟合其余 98% 的列。它实际排第 3，说明模型用到了它，只是没有把它放在第一。gain 的具体数值还在队列里重算，输出 `p6/n2_gain_63d.json`，不覆盖 `controls_63d.json`。
