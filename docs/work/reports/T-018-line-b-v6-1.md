## 1. 结论

| 问题 | 结论 |
|---|---|
| 两颗种子在完整日历 / 新数据上是否可复现 | IC 量级上可复现：R 方案（复刻原切点）与原预测在修正标签下 63d 0.101（原 0.103）、12d 0.066（原 0.069）。这不是逐位相同：Codex 独立重训的两个单折与存储分数 Spearman > 0.99999999998，最大绝对浮点差约 1e-7～5e-7 |
| 连续样本外（C）的真实成交表现 | **63d：年化净超额 +4.74%、IR 0.61、16 次调仓；12d：+0.72%、IR 0.11**。两者都**未过闸门** |
| 主线 B 的板块专用 Ridge 是否有增益（预登记操作规则） | **按规则三个板块都未检测到增益**：主板 P−C +0.002（区间含 0），创业板 −0.018、科创板 −0.063（点估计为负）。原区间是独立自助法、没有处理 63d 标签重叠；按时间块的敏感性，创业板、科创板的区间在至少一种块长下含 0，**不能说"显著更差"**。本卡只比较主线 B 的 Ridge，**不能据此推出主线 A 的 LightGBM 板块模型应当停用**（§6、§8） |
| T-016 用新分数重做（A 的漏斗改用 B 的 63d C 分数） | 只换打分模型：A 自己 −5.29% → B 的分数 +7.78%（IR 0.44），但分年极不稳定（2025 −27%、2026 +55%），**闸门不通过** |

| v6_1 基本面因子（`fnd_v6_1_validation.json`） | 1,683,972 × 27；16 个入选因子在两版共同的 110 个截面上逐值相同（411,042 行）；2026-04-20 后新增 21 个截面、覆盖率正常。共同截面多在 2021-03 前，**覆盖不到** T-015 补入的 2022–2026 财报更正 |
| 切分演练（`fold_dryrun.py`） | C 方案时间轴覆盖 100%；63d 测试截面 200 个（R 为 112） |
| ±inf 审计（`inf_audit_63d.json`） | 两个短周期因子含 ±inf：`sh_wq44_corr_high_rkvol_5` 95 个、`sh_wq3_rkopen_rkvol_10` 67 个 |

**±inf 的影响（原有管线行为）**：`RidgePredictor` 在训练窗口含 inf 时该列均值 / 标准差为 NaN，标准化后整列被填 0，
即这两个因子在几乎所有折里**实际未被使用**——原 v6 种子和本卡 R / X / C 都是如此。按板块训练时会直接报错（P 方案第 3 折）。
修正（P 出结果前写进卡片）：`--inf-to-nan` 把 ±inf 视为缺失；板块判读比较同一口径的 `P_infnan` 与 `C_infnan`。
`C_infnan` 与 C 的 IC 几乎相同（0.0803 vs 0.0802），说明这一修正本身影响很小。

## 6. 板块模型：预登记规则判读 `[实测]`（`board_verdict.json`）

同一 `--inf-to-nan` 口径，P（主板 / 创业板 / 科创板各自训练）与 C（统一训练）在同板块、同截面的 RankIC 配对差：

| 板块 | IC（P） | IC（C） | P − C | 95% 区间（独立自助法，预登记） | P 更好的截面比例 | 预登记操作判据 |
|---|---:|---:|---:|---|---:|---|
| 主板 | 0.0747 | 0.0729 | +0.0019 | [−0.0025, +0.0062] | 51% | 未检测到增益 |
| 创业板 | 0.0763 | 0.0940 | −0.0177 | [−0.0260, −0.0097] | 38% | 未检测到增益 |
| 科创板 | 0.0162 | 0.0788 | −0.0626 | [−0.0823, −0.0430] | 34% | 未检测到增益 |
| 全部 | 0.0659 | 0.0803 | −0.0144 | [−0.0287, −0.0002] | 40% | — |

**时间依赖敏感性**（第二轮修订补充，事后分析，不替换预登记主检验；`board_block_sensitivity.py` / `.json`）。
相邻周频截面的 63d 标签重叠，配对差的一阶自相关 0.75–0.83，独立自助法的区间偏窄。改用移动块自助法（块长按周频截面计）：

| 板块 | 块长 1（= 独立） | 块长 13 | 块长 26 |
|---|---|---|---|
| 主板 | [−0.0025, +0.0063] | [−0.0065, +0.0093] | [−0.0027, +0.0073] |
| 创业板 | [−0.0260, −0.0098] | [−0.0343, +0.0002] | [−0.0326, −0.0044] |
| 科创板 | [−0.0824, −0.0432] | [−0.1180, −0.0068] | [−0.1275, +0.0038] |
| 全部 | [−0.0287, −0.0002] | [−0.0522, +0.0194] | [−0.0498, +0.0150] |

- **按预登记操作判据：三个板块都"未检测到增益"**。这一判读不受块长影响（判据是"均值 ≤ 0 或区间含 0"）。
- **不能说"显著更差"**：创业板（块长 13）、科创板（块长 26）的区间含 0。"未检测到增益"也不等于"证明没有增益"。
- **本卡只比较主线 B 的 Ridge 板块模型**。预登记时把结论直接连到"停用主线 A 的 LightGBM 板块模型"，这是从一个模型族外推到另一个模型族，
  Codex 第二轮指出不成立，本报告接受并撤回这一推断。主线 A 板块模型的去留见 §8。
- 科创板专用模型 IC 最低（0.016）：科创板 2019 年才开板，单独训练的样本少。这是可能的原因之一，本卡没有专门检验。

## 7. T-016 用新分数重做（`t016_redo_result.json`）`[实测]`

只换 B 的预测文件（63d C），其余规则不变：对齐 ≤ 14 天，16 个季度调仓日全部对齐（原 T-016 只有 8 次半年调仓）。

| 变体 | 年化净超额 | IR | 绝对回撤 | 分年 |
|---|---:|---:|---:|---|
| 1 A 自己的打分 | −5.29% | −0.47 | −40.3% | 22 −4.7 / 23 −2.6 / 24 −11.6 / 25 +1.3 / 26 +1.7 |
| **2 B 的分数、A 的候选池（主比较）** | **+7.78%** | 0.44 | −32.6% | 22 −1.5 / 23 +3.3 / 24 +18.7 / 25 **−27.0** / 26 **+55.1** |
| 3 B 的分数、静态 1374 池 | +10.56% | 0.66 | −30.6% | 22 −1.5 / 23 −0.5 / 24 +18.7 / 25 −4.7 / 26 +35.4 |
| 4 B 的分数、全市场 Top-30 | +7.48% | 0.52 | −38.0% | 22 −2.8 / 23 +1.1 / 24 +10.8 / 25 −11.3 / 26 +39.7 |

- 主比较（2 vs 1）方向明确，但 30 只集中持仓的分年波动极大，2025 −27% 与 2026（前 9 个月）+55% 主导了均值；**闸门不通过**。
- 这比原 T-016（8 次调仓，−2.6%）有改善，原因主要是 C 方案让每个季度都有对齐的分数；但"B 的打分在 A 的漏斗里有效"仍缺乏稳健证据。
- 不挑最好的变体：变体 3 / 4 是候选池敏感性，不作为结论。
- 第二轮修订补充：T-016 本身因"主比较两边的候选池不一致、事前规则证据不足"被 Codex 驳回。本节沿用 T-016 的比较框架，
  同样存在候选池不一致的问题，只能算回顾性探索，不能当作"B 的打分比 A 好"的纯模型效应证据。

## 7½. 板块判读与报告口径的关系
板块判读用 `*_infnan` 口径；第 4、5 节的 IC 与 NAV 用原 C 口径（预登记）。两者 IC 相差 0.0001，结论不受口径影响。
