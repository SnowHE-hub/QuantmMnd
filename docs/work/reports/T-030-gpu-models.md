## 3. 增益从哪来

1500 池日均 RankIC（同一文件 `ic_pool_mean`）：Ridge 0.09212126694753194；XGBoost 0.13608921472736654；LightGBM（CPU）0.13668673169076095；MLP 0.13684130470248954；TabM 0.13713258102208878；GRU 0.13935951583796058；ALSTM 0.1419642589585346；ENS 0.14543403614058106；序列融合 0.15184614420452328；CatBoost 0.11948885300566328。

对 Ridge 的配对差里，XGBoost、TabM、序列融合、LightGBM、MLP、GRU、ALSTM 都是「检测到增益」。CatBoost 和只含两棵树的等权是「未检测到增益」。探索性比较里 MASTER 和 ENS+MASTER 也是「检测到增益」（`p6/exploratory_20d.json`，不是预登记主比较）。

CPU 上的 LightGBM 与 GPU 上的 XGBoost 几乎一样。序列模型只比树和 MLP 略高。**增益是普遍的，不能归因于 GPU，也不能归因于深度结构。**
