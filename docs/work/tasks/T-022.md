## 2. 方案（运行前写定）
基线：T-018 的 `C_infnan`（63d 种子，连续样本外，±inf 视为缺失）。两个方案都用同一折、同一特征口径。

- **E1 行业专用模型（IND）**：每折、每个申万一级行业各训练一个 Ridge（行业按 as_of 时点归属）。
  判读：同一截面、同一行业内（有标签 ≥ 20 只）RankIC 配对差 IND − C_infnan；每个截面对行业等权平均；
  移动块自助法（块长 13 个周截面，10,000 次）95% 区间；**均值 ≤ 0 或区间含 0 → "行业专用模型无增益"**。
- **E2 行业特征（SECF）**：统一模型 + 9 个行业特征（`build_sector_features.py`）：
  行业动量 ind_mom_1m / 3m / 6m（行业内等权均值）、个股相对行业动量 rel_mom_3m / 6m、
  行业去均值的基本面 ind_dm_roe_ttm / pb / pe_ttm / operating_profit_yoy（减行业中位数）。
  判读：全市场 RankIC 配对差 SECF − C_infnan，块长 13；**均值 > 0 且区间下界 > 0 → "行业特征有效"**；NAV（63d 配置）作描述。
- 不做：行业轮动（先选行业再选股）——依赖 E1 / E2 的结论，另行预登记。

## 第二轮修订：PIT 重算（运行前写定，2026-10-11 21:50）
- **体系发布日**：取 **2021-12-13**（新版申万行业指数正式推出）；分类标准文件 2021-07-31 发布，取更晚的日期是保守选择。
  `as_of` 早于该日时，行业与全部行业特征一律缺失，不套用未来归属（`build_sector_features_pit.py` → `data/panel/sector_features_v6_1_pit.parquet`）。
- **PIT 反例测试**（`tests/test_t022_sector_pit.py`）：成员 in_date 很早（2015）但体系 2021-12-13 才发布 → 发布前行业与行业特征都是缺失；发布后按成员进出日期。
- **训练**（`train_sector_pit.py`，其余同 T-018 方案 C）：
  - IND：每折、每个行业只用发布后的训练行；运行时断言没有发布前的训练行；
  - CPOST：统一模型，训练行同样只用发布后的——与 IND 的可用训练数据相同，用来隔离"分行业 vs 统一"；
  - SECF：统一模型 + 9 个行业特征，发布前为缺失（标准化后填 0），训练窗口与 C_infnan 相同；
  - IND / CPOST：某折训练窗口里发布后的截面 < 26 周 → 该折两者都不训练、不打分；IND 中某行业训练行 < 200 → 该行业不打分（记录）。
- **判读**（`eval_sector_pit.py`）：
  - E1 主比较 IND − CPOST（同一批截面、同一行业内 RankIC 配对差，块长 13）：均值 > 0 且区间下界 > 0 → "有增益"，否则"未检测到增益"；
  - E1 次要：IND − C_infnan（实际基线）；
  - E2 主比较 SECF_pit − C_infnan（全部截面的全市场 RankIC 配对差，块长 13），同上规则；NAV 作描述；
  - 另报 CPOST − C_infnan（只用发布后数据训练的代价，描述性）。
- 措辞：不显著只写"未检测到增益"，不写"无增益"。
