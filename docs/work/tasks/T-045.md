### 状态（每个调仓决策日 as_of 用 `m_market.market_state` 重算，只用 ≤ as_of 的数据）
- 趋势：沪深 300 收盘低于 60 日均线（`vs_ma60 < 0`）；

- 中证 2000 的历史不够三年时，拥挤状态记为"不可用"，按"不拥挤"处理，报告里写明有多少个决策日是这种情况。

### 三个挑战臂
| 臂 | 规则 | 实现 |
|---|---|---|
| T1 趋势仓位 | 趋势状态为真时，仓位 70%，否则 100% | 近似：每个调仓日确定仓位 e，持有到下一个调仓日；日收益 = e × R 的日收益，现金收益记 0 |
| T2 波动仓位 | 波动状态为真时，仓位 70%，否则 100% | 同上 |
| S1 拥挤时降小盘 | 拥挤状态为真的调仓日，原研究池里流通市值最小的三分之一不进入候选，由更大的股票递补 | 用引擎原样跑（满仓） |

- T1、T2 的近似：
  - 不重新模拟持仓，只缩放 R 的收益；
  - 仓位每变一次，按变动部分收 0.25% 的单边成本（佣金、过户费、印花税和滑点的粗略合计），从当天收益里扣除；
  - 这样处理忽略了部分成交和整手约束，报告里要写明。

### 指标与判定
- T1、T2 的目的是降低**绝对**回撤：
  - 风险指标 = 净值最大回撤之差（臂 − R），以及相对基准的年化净超额之差；
  - **风险改善**：UCB95(Δ 净值最大回撤的绝对值) < 0，且 LCB95(Δ 年化净超额) > −δ_R。
- S1 是满仓的选股变化：沿用 T-042 的口径。
  - 非劣：LCB95(Δ 年化) > −δ_R，且 UCB95(Δ 相对财富最大回撤) < δ_D；
  - 同时报告风险改善：UCB95(Δ 相对回撤) < 0。
- 自助法：块长 20 / 65 日，10,000 次，种子 0；回撤差用同一组自助样本重算。
- 3 个臂 × 2 个期限 = 6 次比较，写明多重比较。
- 处在状态为真的调仓日占比低于 5% 的臂，记为"样本里几乎没有触发"，不做推断。
