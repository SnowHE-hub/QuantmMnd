- [实测] README 首页"v6 HRP 净 Sharpe 0.996"可逐位复现：
  `run_nav_backtest.py --panel alpha_panel_v4 --model models/lgbm_v6_alpha.pkl --weight-method hrp --top 30 --cost-bps 13`
- [代码] `run_nav_backtest.py:106-119` 用**单个**已训练模型给 2019–2026 全部截面打分；
  `models/lgbm_v6_alpha.meta.json` 的 `challenger_tag = v4_round4_2024q4`，即序贯验证第 4 轮（`train_end = 2024-12-31`，24 个训练截面）。
  2019-03-31 至 2024-12-31 的 24 次调仓，模型训练时见过它们的标签 → **样本内**。

  同期 1374 等权宇宙年化 +34.5%。

## 目标
产出主线 A 的**严格样本外**截面分数，并在两种口径下评估：
1. 旧口径（`run_nav_backtest` 的扁平 13bp、无成交约束）——与 README 的 0.996 只差"样本内 → 样本外"这一个变量；
2. 真实成交口径（`ExecutableNavEngine`：T+1 开盘成交、涨跌停/停牌拒单、分层滑点、时变印花税、PIT adv20 选股池）。

## 设计（实现前冻结）
- 面板 `alpha_panel_v4_1`（T-003 修正标签），标签 `forward_return_63d`，特征 = `lgbm_v6_alpha.meta.json` 的 `feature_cols`（42 个）
- 模型超参同 `lgbm_v6_alpha`：`n_estimators=400, num_leaves=31, learning_rate=0.05, early_stopping_rounds=50`；`auto_flip=False`（不在测试期之后决定方向）
- 每个测试截面 t（第 i 个季度）：`val = dates[i-gap-2 : i-gap]`，`train = dates[:i-gap-2]`，`gap = 1` 个季度
  （63 个交易日的标签窗口约等于一个季度；gap=1 保证训练/验证样本的标签在 t 之前结束）
- 训练截面数 ≥ 8 才出分；t 之前的截面不打分
- 旧口径 NAV：复用 `run_nav_backtest.build_daily_nav / calc_metrics`，Top 30，equal 与 hrp，13bp
- 真实成交 NAV：`NavConfig(horizon_td=63, rebalance_step=1, top_n=30, universe_size=1500)`，价格 `alpha_prices_panel_v6.parquet`
