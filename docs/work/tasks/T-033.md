# T-033 · 20d 增益归因：同一套 Ridge，只换特征 / 变换 / 训练行（探索性）

- 状态：assigned
- 实现：Claude（2026-10-19，用户要求"用新特征重训 Ridge 做归因"）
- 分支：`t/033-attribution-forward`（基于 `t/030-gpu-models` 5723f23），worktree `~/projects/qm-t033`
- 性质：**探索性**。不是预登记的确认性比较，不改变 T-030 的任何判定。结论措辞只用"探索性：检测到 / 未检测到差异"。

## 问题
T-030 的 20d 集成比 Ridge C 高 +0.053（RankIC，前 1500 池）。但几乎每个模型族都比 Ridge C 高约 0.045，连 CPU 上的 LightGBM、普通 MLP 也一样；周频训练与日频训练又没有差别（−0.0016）。
增益来自哪里？是**新特征集**、**截面排名变换**、**非线性模型**，还是线性模型多用了日频数据？

## 设计（事先写定，运行前提交）

所有臂都沿用 Ridge C 的配方，逐项照抄 T-028 `train_event_aug.py` 的 20d BASE：
- 外层折：`PurgedWalkForwardSplit(H=20, E=20, rolling 756, n_val=2)`；
- 季度切点 2022-01-04 → 2026-07-01，方案 C 连续样本外；
- 模型：Ridge α = 10；
- 标准化：用训练行（标签非缺失）的均值和标准差（ddof = 1，标准差为 0 时取 1）做 z-score，±inf 视为缺失，标准化后缺失填 0；
- 方向：用 `decide_direction`，只看验证段。

Ridge 用分块累加的闭式解（XᵀX + αI）实现，与 sklearn `Ridge(alpha=10)` 在数学上等价，用来承受日频行的内存。
**A0 必须逐值复现 Ridge C 的已登记预测**：最大绝对差 ≤ 1e-6，方向一致。否则先停下排查，其余臂不跑。

| 臂 | 特征 | 训练行 | 回答的问题 |
|---|---|---|---|
| A0 | Ridge C 原 225 列（35 + 16 短周期 + 16 基本面 + Alpha158），原始值 | v6_1 周频 | 实现核对 |
| A0r | 同 A0，但每列先做当日截面 gauss-rank（与 T-030 的特征变换相同） | v6_1 周频 | 只换截面变换有多大作用 |
| A1 | T-030 特征集：250 个股票列（当日 gauss-rank）+ 26 个市场列，取自 `data/gpu_v1/model/v1` | v6_1 周频，行集合与 A0 相同 | 换成新特征有多大作用 |
| A2 | 同 A1 | 训练窗内全部交易日（日频） | 线性模型多用日频数据有没有用 |

**评估**：沿用 `eval_primary.paired`，在 T-030 冻结的 20d 可评估行上算（`p6/frozen_eval_rows_20d.parquet`，323,783 行、222 个日期）：
- 逐日配对差，块长 13 和 26 的移动块自助，10,000 次，种子 0；报 95% 和 97.5% 区间。
- 报告这些差：A0r − A0、A1 − A0、A1 − A0r、A2 − A1、ENS − A1、ENS − A2。
- 另报各臂相对 Ridge C 的差。

**读法**：只作描述性归因，不设放行门槛。T-030 的增益若主要被 A1 吸收（即 ENS − A1 接近 0），说明来源是特征；若 ENS − A1 仍明显为正，说明来自非线性。
