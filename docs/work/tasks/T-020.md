## 为什么做（[实测] / [文档] 依据）
- 主线 B 的 12d 种子研究层 IC 为正（v6 原预测 IC 均值 0.069），但可执行 NAV 年化净超额为负（完整价格下 −2.34%，T-017）。
- 审计（`docs/plans/executable_nav_audit_20260710.md`）：12d 的主要损耗是成本——换手约 8.95×、成本约 −3.20%/年。
- 现有引擎每次调仓：跌出前 300 名的票全卖；仍在目标内的票每次都调回等权。两者都产生换手。
- 本实验只问一件事：**常见的两种换手控制能否在不改信号的前提下，显著减少成本损耗、提高净超额。**

## 方案（运行前写定，之后不改）
引擎：`quantmind/execution/nav_turnover.py` 的 `TurnoverControlledNavEngine`（继承 ExecutableNavEngine，只改"选目标"和"是否调仓"两处；
两个参数都不设时与父类逐笔相同，有测试）。其余配置同原 12d：Top 300、PIT adv20 选股池 1500、T+1 开盘成交、分档滑点、涨跌停 / 停牌、现金约束。

| 方案 | 内容 | 参数（事先固定，不调） |
|---|---|---|
| B0 基线 | 原引擎行为 | rebalance_step 3 |
| B1 缓冲带 | 已持有且排名仍在前 600 的票不卖；空位按排名补新票 | exit_rank = 600（= 2 × top_n） |
| B2 容忍带 | 目标内持仓偏离等权目标 ≤ 50% 时不调仓 | drift_band = 0.5 |
| **B3 = B1 + B2** | **主比较（预先指定）** | 同上 |
| B4 降频 | 每 6 个周截面（30 个交易日）调仓一次 | rebalance_step 6 |

参数取值依据：缓冲带取 2 倍组合规模、容忍带取 50% 都是常见的经验取值 `[推断]`；**不做网格搜索**。

## 判读规则（运行前写定）
1. **主估计量**：B3 与 B0 日净收益差 d_t 的年化均值（×252）。两者基准相同，所以这也是日超额收益之差。
   95% 区间：移动块自助法，块长 15 个交易日（一个调仓间隔），10,000 次，种子 0。
2. **"换手控制有效"**：主输入上 均值差 > 0 **且** 95% 区间下界 > 0。
3. **"12d 种子可用"**：只看 B3 是否通过原闸门（`GateThresholds(max_drawdown=0.15)`，年化净超额 ≥ 5%、IR ≥ 1、每年为正；阈值不变）。
4. B1 / B2 / B4 只作描述（各自的均值差与区间照报），**不得把其中最好的一个作为结论**；任何关于它们的说法标"探索性"。
5. 同时报告：毛超额（扣成本前）、成本损耗、年化双边换手、成交 / 拒单——用来区分"省了成本"和"损失了信号"。
6. 稳健性输入的结果只用于检查方向是否一致，不参与第 2、3 条的判定。

## 结果（2026-10-11）
- 主输入（T-018 方案 C 的 12d 预测）：B0 净超额 +0.72% / 年（毛 +5.60%，成本 4.88%，换手 24.5×）；B3 +1.21%（毛 +4.88%，成本 3.67%，换手 17.1×）
