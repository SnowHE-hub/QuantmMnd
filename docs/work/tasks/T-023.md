## 背景
- T-018 / T-020：12d 种子毛超额约 5.6%、成本 4%–5%，净 +0.72%；63d 种子连续样本外 +4.74%（IR 0.61）。中间期限没有测过。
- "63d 是不是日频数据的极限"：不是。日频数据可以构造任意 ≥ 1 日的期限；期限越长，独立样本越少、换手越低。本卡只补 20d / 40d。

## 方案（运行前写定）
1. 标签：`build_labels_20_40.py` 用 v6_1 面板**同一个** `compute_forward_returns_delist_aware`、同一价格表与日历，在 374 个周截面上算 20d / 40d；
   同时重算 12 / 21 / 63d 与面板逐值比较，**不一致则不写文件**。输出 `data/panel/labels_extra_v6_1.parquet`。
2. 训练：`train_horizon.py`，除标签、隔离带（E = H）与切点（季度，2022-01-01 → 2026-07-01）外全部沿用 T-018 方案 C：
   特征 = 63d 种子的超集（35 + 16 短周期 + 16 基本面 + Alpha158）；Ridge(α=10)；PurgedWalkForward(rolling 756, n_val=2)；
   连续样本外测试窗口 (C_k+E, C_{k+1}+E]；±inf 处理与 T-018 C 相同（保持同一管线，已知两个因子被静默弃用，见 T-018）。
3. 评估：`eval_horizons.py`，12d / 20d / 40d / 63d 四个方案 C 同一套 IC 与 NAV（Top 300 / 选股池 1500 / 完整价格 / v6_1 amihud），
   调仓步长 = H / 5 个周截面（12d 3、20d 4、40d 8、63d 13）。
4. 判读（描述性比较，不挑最好）：
   - 每个新期限与 63d C 的日净收益差，移动块自助法（块长 20，10,000 次）95% 区间
   - 某新期限 **IR 高于 63d C 且配对差区间下界 > 0** → "值得作为新种子继续"；否则"维持 63d 为主种子"
   - 闸门照原规则报告；另报相对基准回撤（闸门的绝对回撤判据问题见 T-020 §4）
   - 12d / 63d 的数字应与 T-018 eval 相同（一致性检查）
