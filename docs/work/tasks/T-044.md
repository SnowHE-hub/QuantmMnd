### v2 核对（代码，不用模型）
对转写正文里的每个占位符 `{{c:角色:编号}}`，取它所在的句子，和这条声明骨架里的原文比较四类标签：

- 主体：子公司 / 控股股东 / 实际控制人 / 参股公司 / 母公司 / 公司本身；
- 阶段：计划（拟、计划、预案、草案、预计）↔ 已实施（已、完成、实施、实施完毕）；
- 期间：句子里出现的年份、季度与声明的 period 不一致。

判定：句子里出现了与原文**相反**的方向词，或者原文没有、句子里新出现的主体词或阶段词，或者与声明期间冲突的年份，记为一条错误；有错误就退回模板文本（与 v1 相同的降级）。
一句里有多个占位符时，只检查该占位符前后最近的一段（以逗号、分号切开）。
