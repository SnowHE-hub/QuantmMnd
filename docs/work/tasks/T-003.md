## 目标
v4 面板的 `forward_return_21d / 63d` 改为用**单一一致的价格基准**计算，
消除快照间前复权基准漂移与末段拼接错误。产出新文件，不覆盖旧文件。

## 背景与证据
- [代码] 标签由 `quantmind/features/panel.py::compute_forward_returns` 计算，
  `scripts/build_full_panel.py:419` 调用；价格宽表来自各快照 `prices.parquet` 的 `close`
  （`_price_pivot_from_snapshots`），末段由日线 parquet 的 `adj_close` 续接（`_extend_pivot_with_daily_parquet`）
- [实测] 快照 `close` 是**各自以快照日为基准的前复权价**：000759.SZ 在 1624 个跨快照日期中有 398 个 close 不一致，
  原始字段 `pre_close` 0 个不一致
- [实测] 以 `pct_change` 连乘为真值（跨快照 0 / 2,361,998 处不一致）：63d 标签误差 > 10% 占 2.91%；
  **2024-09-30、2024-12-31 两个截面约 87% 的标签误差 > 10%，Spearman(存储, 真实) ≈ 0**
- [代码] `quantmind/features/labels.py` 是死代码（只被测试调用），不要改它
- 研究主线 v6 的 `scripts/survivorship/p2_build_v6.py::compute_forward_returns_delist_aware` 用 adj_close，不受影响，可参考

## 语义约束（必须保持不变）
- horizon 定义不变：以 as_of 当天或之前最后一个交易日为基准，取**合并交易日历**上其后第 h 个交易日为目标日
- 目标日无价（停牌）→ NaN，与现行为一致
- 不引入退市感知逻辑（那是 v6 的语义；若认为需要，写进实现说明交回 C1）
