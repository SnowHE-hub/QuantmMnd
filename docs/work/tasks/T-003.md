## 目标
v4 面板的 `forward_return_21d / 63d` 改为用**单一一致的价格基准**计算，
消除快照间前复权基准漂移与末段拼接错误。产出新文件，不覆盖旧文件。

## 背景与证据
- [代码] 标签由 `quantmind/features/panel.py::compute_forward_returns` 计算，
  `scripts/build_full_panel.py:419` 调用；价格宽表来自各快照 `prices.parquet` 的 `close`
  （`_price_pivot_from_snapshots`），末段由日线 parquet 的 `adj_close` 续接（`_extend_pivot_with_daily_parquet`）
- [实测] 快照 `close` 是**各自以快照日为基准的前复权价**：000759.SZ 在 1624 个跨快照日期中有 398 个 close 不一致，
  原始字段 `pre_close` 0 个不一致
- [实测] 以 `pct_change` 连乘为真值（跨快照 0 / 2,361,998 处不一致）：63d 标签误差 > 10% 占 2.91%；
  **2024-09-30、2024-12-31 两个截面约 87% 的标签误差 > 10%，Spearman(存储, 真实) ≈ 0**
- [代码] `quantmind/features/labels.py` 是死代码（只被测试调用），不要改它
- 研究主线 v6 的 `scripts/survivorship/p2_build_v6.py::compute_forward_returns_delist_aware` 用 adj_close，不受影响，可参考

## 语义约束（必须保持不变）
- horizon 定义不变：以 as_of 当天或之前最后一个交易日为基准，取**合并交易日历**上其后第 h 个交易日为目标日
- 目标日无价（停牌）→ NaN，与现行为一致
- 不引入退市感知逻辑（那是 v6 的语义；若认为需要，写进实现说明交回 C1）

## 实现说明

**旧实现的第二个缺陷（卡片未写，实现中发现）** `[代码]`：旧 `_extend_pivot_with_daily_parquet` 用 `keep="last"` 合并，

**补充修复（2026-10-10 晚，第 3 个提交）：缺数据 ≠ 停牌** `[实测]`
- 发现过程：生成不保留掩码的 v4_2 后，用 T-015 补齐的无缺日价格表（close×adj_factor）独立核验，
  63d 有 1,017 个样本偏差 >0.5%，其中 1,013 个集中在 2024-12-31 截面（Spearman 0.556）；而 `tools/label_audit.py` 报 PASS。

  这正是本卡"独立来源交叉核验"一节担心的情形。v4_1 因保留 v4 掩码，带标签的票都被快照覆盖，不受影响。

## 重验修复（2026-10-11，回应 Codex REJECT `codex/acceptance-2026-10:docs/work/acceptance/T-003.md`）

**驳回理由 1：筛票后交易日历缩水** `[代码]`
- `_load_return_sources` 的覆盖改为**按股票过滤之前**计算，每个来源记 (实际有数据的交易日, 出现过的股票)，不再是 (起, 止) 区间。
- 新增 `_label_axis` / `_align_to_axis`：标签日期轴 = 各来源有数据的日期（不按股票过滤）∪ 来源区间内的**独立交易日历**
  （`--trade-calendar`，默认 `data/lake/trade_cal_sse.parquet`，T-015 从 Tushare `trade_cal` 取得）。收益指数宽表 reindex 到该轴，
  面板票全体停牌、其他票交易的日子留在轴上，horizon 不再错位。来源里出现日历范围内的非交易日 → ValueError。
- 语义说明：卡片"语义约束"里的"合并交易日历"现在指上述轴；来源完整时与原定义相同。

**驳回理由 2：来源覆盖完整性** `[代码]`
- 覆盖只认来源**实际有数据的日期**：来源内部整日缺失的日期不算被它覆盖；日历里有、没有任何来源覆盖的日子 = 未知，
  窗口含未知日的标签置 NaN（`_drop_unobserved`，未改）。
- `tools/label_audit.py` 同步：同样的轴与覆盖定义、`--trade-calendar` 参数；修正 `--help` 的百分号格式化错误。
  该文件在 allowed_paths 之外（第 3 个提交起），技术范围已获 Codex 认可，**请 C1 补批**。

**新增测试**（`tests/test_label_price_basis.py`，共 19 个，全部通过；新增的 6 个在修复前的代码上全部失败）`[实测]`
- 面板只含停牌票、其他票交易（Codex 反例；有/无独立日历两种）：旧行为目标日后移 2 天得 1.01²³−1，新行为 1.01²¹−1
- 目标日停牌 → NaN；来源内部整日缺失 → 跨该日的标签 NaN、不跨的照算、补一份覆盖该日的来源后恢复
- 票池变化（离开票池后未覆盖 → NaN；进入票池前无基准价 → NaN）；来源含非交易日 → 报错
