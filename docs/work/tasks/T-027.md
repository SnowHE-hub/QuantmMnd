## 动机 `[实测]`
- T-025：2026 年主线 B 相对选股池等权的 beta 为 1.2–1.45，7 月跌 18–32%、8 月涨 19–35%，9 个月结果对调仓日期极敏感。
- 问题：如果让组合在行业、市值、beta 上与选股池保持一致，能否降低 beta 和相对回撤，而不明显损失超额？

## 方法
- 新模块 `quantmind/execution/nav_stratified.py`：`StratifiedNavEngine`。决策日把通过选股池与近期成交过滤的候选按维度分组，
  每组名额 = 300 × 组内候选数 / 候选总数（最大余数法），组内按分数取前几名；组合仍等权。成交、成本、涨跌停等全部沿用父类。
  不分层时与 `ExecutableNavEngine` 逐笔相同（测试覆盖）。数值维度在当期候选中按排名五等分；缺失值单独成组。
- 暴露数据（都按 as_of 时点）：
  - 行业：`data/panel/sector_features_v6_1.parquet` 的 `sw_l1`（T-022，申万 2021 时点成分；2021-07 之前是把 2021 体系往回套，见 T-022 限制）；
  - 市值：`data/panel/fundamental_factors_v6_1.parquet` 的 `log_circ_market_cap`；
  - beta：`data/panel/alpha_panel_weekly_v6_1_base.parquet` 的 `beta_252d`。
- 变体（运行前写定，不增不减）：

| 变体 | 分层维度 |
|---|---|
| S0 基线 | 无（= T-018 方案 C 的 NAV 配置） |
| S1 | 申万一级 |
| S2 | 流通市值对数五分位 |
| **S3（主比较）** | beta_252d 五分位 |
| S4 | 申万一级 × 市值五分位 |

- 种子：**主分析 63d**（`data/bakeoff/preds_v6_1/ridge_63d_v6_1_C_infnan.parquet`，持有 63 日、每 13 期调仓、闸门回撤阈值 0.12）；
  **探索性 20d**（`ridge_20d_v6_1_C.parquet`，与 T-023 相同：持有 20 日、每 4 期调仓、阈值 0.15）。
- 其余配置与 T-018 / T-023 相同：Top 300、选股池 PIT 成交额前 1500、价格 `alpha_prices_panel_v6_20261009`、滑点按 v6_1 面板 amihud 分档。

## 指标与判读规则（运行前写定）
- 主估计量：Sk − S0 的日净收益差年化均值；移动块自助法（块长 = 一个调仓间隔：63d 65 日、20d 20 日；10,000 次；种子 0），
  报 95% 区间与 Bonferroni 98.75% 区间（4 个对比）。
- 风险指标：事后 beta（组合日净收益对选股池等权日收益）、相对回撤（净值 / 基准净值的最大回撤）、绝对回撤、IR、波动率；2026 年单独再报一次（描述性）。
- 诊断：调仓日目标组合与候选池的 beta 均值差、市值均值差、行业构成差（Σ|份额差| / 2）。
- **"有效"**（每个变体分别判）：事后 beta 比 S0 至少低 0.10，**且**相对回撤比 S0 浅，**且**年化净收益差点估计 ≥ −1%，**且** IR 降幅 ≤ 0.10。
- **"收益改善"**：Bonferroni 98.75% 区间下界 > 0。
- 建议规则：主比较 S3 有效 → 建议主线 B 默认采用 beta 分层；S3 无效但其他变体有效 → 只报告，不改默认（避免事后挑选），另开卡确认。
- 闸门：各变体按现行闸门（阈值不变）报告是否通过；不因本卡改阈值。

## 自检
- S0 应与 T-018 的 `C_infnan` 63d 结果一致（年化净超额 +5.03%）；20d S0 应与 T-023 的 20d 结果一致（+3.44%）。不一致则先查原因、不判读。

## 限制
- 分层只控制组合构成与候选池一致，不是优化器意义上的严格中性（组内仍可偏向高 beta / 小市值）。
- 样本 2022–2026（63d 约 16 次调仓），区间会很宽；结论以规则为准。
- 运行脚本：`docs/work/evidence/T-027/run_risk_strata.py`；输出 `docs/work/evidence/T-027/{63d,20d}/`。

## 结果（2026-10-11 运行；详见报告）
- 自检通过：S0 63d +5.03%、20d +3.44%，与 T-018 / T-023 一致。
- **63d：四个变体都不有效**。主比较 S3（beta 分层）：收益差 −3.31% [−10.94%, +0.54%]，beta 只降 0.07，相对回撤更深（−18.9% vs −13.2%），IR 0.64 → 0.22。
- 20d（探索性）：也都不满足规则；S4 行业×市值 IR 0.41 → 0.99、相对回撤 −15.4% → −7.1%，收益差 +1.58% [−4.11%, +7.35%]。
- 高 beta 的原动机没有被全样本支持（全样本基线 beta 0.97 / 0.99，高于 1 的只有 2026 年）；固定变体未达到预登记阈值。规则与判读不变、不重判。
- 按规则：主线 B 默认组合构建不改。
