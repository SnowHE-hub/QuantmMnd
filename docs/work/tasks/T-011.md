## 做法与取舍
不加新 marker：加 marker 会把这些测试从**本地**默认集里也排除，而本地它们能跑、有价值。
改为 `pytest.mark.skipif(<依赖不存在>)`：本机有 `.env` / 数据 / FlagEmbedding 时照常运行，CI 与新 clone 上跳过并给出原因。
这样 T-002 的验收条件"CI 选中集合 = 本地默认集合 − integration"仍然成立（集合不变，只是部分用例在 CI 上 skip）。
