## 实现（`quantmind/line_a/formal.py`、`configs/line_a_v2/formal.yaml`）
- **规则**（全部是 T-052 验证过的主配置，事先固定）：
  - ENS20 冻结第 18 折模型包的每日 F3，周频网格每 4 期调仓，持仓仍在前 2N 就不卖，次日开盘成交；
  - 佣金万 2.5、最低 5 元；过户费 0.001%；印花税 0.05%；参与率 5%。

  | 档 | 持股 | 板块 |
  |---|---|---|
  | 10 万 | 10 只 | 主板 + 创业板 |
  | 100 万 | 30 只 | 全部 |
  | 1000 万 | 100 只 | 全部 |

- **纸面账户**：每天用 T-052 的模拟器从首次调仓日重放到当天，得到持仓和明天开盘的委托（股数按当天收盘价估算）。
  - 首次调仓日之前出"建仓预览"；
  - go_live = 2026-10-26，首次调仓日 = 2026-10-28（周频网格）。
- **日报**：`data/line_a_v2/formal/<日期>/report.{md,json}`，Markdown 复制到 `D:\MCS_26S2课程资料\quantmind\formal_reports\`。内容：
  - 三档纸面账户；
  - 明日委托，买不起一手的单独列出；
  - 当前持仓；
  - 相关股票的研究要点、风险提示、当天事件；
  - Agent 大脑的意见。
- **开关**：
  - `kill_switch: true` 只出报告、不出委托；
  - `enabled: false` 回到纯影子。
- **每日运行**：`daily_shadow.sh` 第 6 步（软步骤）`formal --with-brain`。
- **自动启动**：`scripts/line_a/daily_auto.sh`。
  - 北京时间交易日 21:30；判断交易日用 `data/lake/trade_cal_sse_future.parquet`（`scripts/data_pipeline/fetch_future_calendar.py`）；
  - 自动找上一次完成的日期；已完成或正在运行就退出。
  - **安装 crontab 这一步被 Claude Code 的安全检查拦下**（持久化配置），需要用户自己加，命令见最终汇报。
- 旧的生产日更（主仓库 `scripts/daily_update.py`，10-20 起在 crontab 里暂停）不动。
