- 依赖: 无

## 目标
面板是截面 z-score 落盘的（[实测] pe_ttm 均值约 3e-19、标准差 0.913），
但 LLM prompt 与 HTML 报告把 z-score 乘 100 加 `%` 显示（贵州茅台 "ROE_TTM 179.52%"）。改为如实呈现。

## 背景与证据（[代码]）
- `quantmind/models/llm_reranker.py` 第 295、297、298、299 行（进 LLM prompt）
- `scripts/run_llm_rerank.py` 第 257、259、260、261 行（进 HTML 报告）
- `llm_reranker.py:87` 系统提示写"CSI300 指数成分股"，实际票池是 alpha 1374
- `quantmind/models/dpo_data_builder.py` 用随机生成的**原始量纲**数据构造偏好对，
  与推理时的 z-score 分布不一致（本卡只加文档警示，不改行为）

## 要求
- 这四个字段与表头改为"截面标准分"语义：不加 `%`，保留 2 位小数；表头与系统提示说明"0 为截面均值，正值高于平均"
- 系统提示中的票池描述与实际一致
- `dpo_data_builder.py` 模块文档加一段警示：训练分布为原始量纲、推理为标准分，二者不一致
