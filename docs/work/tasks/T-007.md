# T-007 · 匿名化消融实验（升级方案 §11.3）
- 状态: created
- 流程: **C1 定稿设计 → G1 评审设计（先于执行）→ C3 执行 → C2 验收数字**
- 依赖: T-003（需要修正后的真实收益）、T-006（schema 与关 thinking）

## 要回答的问题
LLM listwise rerank 的增益（若有）来自因子推理，还是来自预训练对股票的记忆？
[实测] Bonsai 27B 的知识截止估计在 2025-01～03，QuantMind 全部 rerank 回测截面都在其"知情期"内。

## 设计（预注册：执行前冻结，结果出来后不得修改判读规则）
- 截面：alpha_panel_v4_1 中 63d 标签完整的全部季度截面（约 25 个）
- 每个截面：LGBM 粗排取 Top-30 → LLM 输出 Top-10（固定 JSON schema，ticker 用 enum 约束）
- 三组，同一批输入：
  - **A 对照**：真实代码 + 真实因子值
  - **B 匿名**：代码替换为随机 ID，删除一切可识别公司的字段；**保留行业**
  - **C 空因子**：真实代码 + 因子值在候选间随机打乱
- 指标：`rerank_lift = RankIC(LLM 排序, 真实 63d 收益) − RankIC(LGBM 排序, 真实 63d 收益)`，在 Top-30 候选内计算
- 统计：按截面配对；报均值、bootstrap 95% 置信区间（10,000 次）、符号检验
- 判读矩阵：见升级方案 §11.3；**"不确定"是合法结论**（约 25 个截面，区间预计较宽）

## 验收（C2）
1. 随机抽 3 个截面 × 3 组重跑，lift 复现（温度 0、固定 seed）
2. 检查 B 组全部 prompt 日志：不得出现任何真实代码或公司名
3. 全部约 75 次调用 JSON 合法率 100%，ticker 全部落在候选集
4. 报告中的判读严格按预注册矩阵
