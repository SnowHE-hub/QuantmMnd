## 设计（预注册：执行前冻结，结果出来后不得修改判读规则）
- 截面：alpha_panel_v4_1 中 63d 标签完整的全部季度截面（约 25 个）
- 每个截面：LGBM 粗排取 Top-30 → LLM 输出 Top-10（固定 JSON schema，ticker 用 enum 约束）
- 三组，同一批输入：
  - **A 对照**：真实代码 + 真实因子值
  - **B 匿名**：代码替换为随机 ID，删除一切可识别公司的字段；**保留行业**
  - **C 空因子**：真实代码 + 因子值在候选间随机打乱
- 指标：`rerank_lift = RankIC(LLM 排序, 真实 63d 收益) − RankIC(LGBM 排序, 真实 63d 收益)`，在 Top-30 候选内计算
- 统计：按截面配对；报均值、bootstrap 95% 置信区间（10,000 次）、符号检验
- 判读矩阵：见升级方案 §11.3；**"不确定"是合法结论**（约 25 个截面，区间预计较宽）

## 验收（C2）
1. 随机抽 3 个截面 × 3 组重跑，lift 复现（温度 0、固定 seed）
2. 检查 B 组全部 prompt 日志：不得出现任何真实代码或公司名
3. 全部约 75 次调用 JSON 合法率 100%，ticker 全部落在候选集
4. 报告中的判读严格按预注册矩阵

## 设计 v2（2026-10-11，回应 Codex 设计评审 `codex/acceptance-2026-10:docs/work/reviews/T-007.md`）

> 起草：Claude Code 桌面版 · Opus 5.5（用户授权"需要决定的按 Claude 的推荐走"，代行 C1 定稿）。
> **状态：设计定稿稿，待 G1 设计评审；G1 通过前不执行正式实验。** 下文取代上面"设计"一节中与之冲突的部分。

### 1. 要识别的量（estimand）
主问题：**公司标识对 LLM 排序增益的增量**（记忆），= A − B（两组信息完全相同，只差代码是否真实）。
次要：只凭标识能排出什么（C，记忆的上界）；零信息时的格式 / 位置偏差（D，对照）。
不再用旧 C 组（因子打乱、保留真实 LGBM 分数与排名）——它不是纯空因子对照（Codex 意见）。

### 2. 四组（同一批 Top-30 候选、同一 system prompt、同一日期）
| 组 | 代码 | 因子值 | LGBM 分数 / 排名 | 候选顺序 |
|---|---|---|---|---|
| A | 真实 | 真实 | 真实 | LGBM 排名 |
| B | 匿名 S01–S30（每截面独立随机映射） | 真实 | 真实 | LGBM 排名 |
| C | 真实 | — | — | 随机（固定种子，与 D 相同） |
| D | 匿名 | — | — | 随机（同 C） |
- C、D 的 user prompt 只列候选标识，明确写"本组不提供因子值与 LGBM 排名"；LGBM 排名只用于评估 lift，不进 C、D 的 prompt。
- **行业**：正式删去"B 组保留行业"——四组都不含行业（生产 prompt 本来就没有行业列；加入行业会增加可识别性）。
- **日期**：四组都保留。主实验针对个股身份记忆，**不隔离市场整体记忆**；若 G1 要求隔离，另做四组同时隐藏日期的敏感性实验（不能只对 B 去日期）。

### 3. 匿名化检查与边界
- 对 B、D 的**完整 payload**（所有文本字段 + 输出 schema）检查：不含任何上市 / 退市公司的 6 位代码（不限候选集）、简称、去 ST 前缀的简称、全称、英文名
  （词典 = `stock_basic_full` ∪ `stock_basic_full_20261009`，5,557 个代码、17,731 个名称）；schema 的 enum 只允许 `S\d{2}`。
  与固定模板文字重合的名称（本次只有"标准"，来自"标准分"）列入 manifest 的 `template_collisions_excluded`。
- 真实代码映射只在 `private_mapping.jsonl`，不进 `requests.jsonl` 的 payload；执行端只发送冻结 payload（加 model 字段）。
- **边界**：日期、精确因子向量、LGBM 分数与排名仍可能被用来识别个股；本实验不承诺消除预训练记忆，只测"标识本身"的增量。

### 4. 样本（重新冻结：`docs/work/evidence/T-007/t007_v2/`）
- 候选：T-010 主结果的样本外分数 Top-30（不变，接受）；标签改用 `alpha_panel_v4_2`（不保留 v4 掩码、价格到 2026-10-09），
  因而 **19 个截面全部纳入**（v1 只有 15 个）。`selection.csv` 记录每个截面的纳入 / 剔除与原因（本次无剔除）。
- 冻结：76 条请求（19 × 4）；manifest 记录设计版本、各输入文件 sha256（分数、面板、两份 stock_basic）、各组 prompt 模板 sha256、
  解码配置（温度 0、seed 0、max_tokens 1500、关 thinking）、知识截止区间 [2025-01-01, 2025-03-31]、冻结文件 sha256。
- `t007_v1/` 保留作历史，不再使用。

### 5. 预注册判读（写在 `scripts/ablation_analyze.py` 顶部，执行前冻结）
- 指标：lift = Spearman(LLM 顺序, 真实 63d) − Spearman(LGBM 顺序, 真实 63d)，Top-30 内（LLM 的 Top-10 在前、其余按 LGBM 排名接后）
- 区间：按时间顺序的移动块自助法（块长 2，10,000 次）；同时报告独立自助法
- 多重比较：主族 4 个量（A、B、A−B、C），Bonferroni；"> 0 / < 0" 用 98.75% 双侧区间；"≈ 0" 用 TOST（97.5% 区间整体在 ±δ 内，**δ = 0.05**）；其余"未定"
- 有序判读：完整性失败 → 不判读；D 偏离 0 → 对照失败、不判读；A < 0 → 异常；B < 0 或 A−B < 0 → 异常（修复 Codex 反例：B 整体为负不再被判"部分记忆"）；
  因子推理（A > 0、B > 0、A−B ≈ 0）；以记忆为主（A > 0、A−B > 0、B ≈ 0；C > 0 时注明佐证）；部分记忆（A > B > 0）；
  无可检测贡献（A ≈ 0、B ≈ 0）；其余"不确定"（合法结论）
- **配对完整集合**：四组 × 全部截面都必须有同一 run_id 的合法响应（JSON、schema 全字段、ticker 在候选内且不重复、finish_reason=stop、思考为空），
  任何一条失败即**关闭因果判读**，只报告失效请求；不再各组独立丢截面
- 同时报告：配对差逐截面明细、A−B 的符号检验与一阶自相关、各组绝对 IC 与 Top-10 平均 63d 收益（相对弱基线的 lift 不等于可交易能力；本实验不做成交与成本检验）
- 判读只描述统计结果，**不得**直接推出"按比例折价"等投资动作

### 6. 可复现性
- `request_id` = payload 的 sha256；执行端校验 payload 未被改动
- `run_id` = sha256(requests.jsonl 哈希 + GGUF 内容哈希 + 模型名)；响应逐条带 run_id / request_id；断点续跑只跳过同一 run 已成功的请求，换模型不会混入旧响应
- 运行信息（GGUF 哈希、服务端 /props）写 `run_<id>.json`；分析检查单一 run / 模型、请求集合完整、无重复、schema 与排名语义

### 7. 统计功效（交 G1 决定）`[实测]`
随机输出（`--mock`）在这 19 个截面上：各组 lift 的 98.75% 区间半宽约 0.11–0.12，TOST 区间半宽约 0.10。
即**即使 LLM 毫无作用，δ = 0.05 的"≈ 0"也几乎不可能被确认**，最可能的结论是"不确定"。粗算达到 δ = 0.05 需要约 90 个截面。
可选：(a) 接受"不确定"为大概率结果；(b) 放宽 δ（需事先给出实际意义的理由）；(c) 增加截面（例如用主线 B 的周频打分构造月度截面，需另行冻结）。

## 设计 v3（2026-10-11，回应 G1 评审："v2 暂不通过，修改后重新冻结"）

> 起草：Claude Code 桌面版 · Opus 5.5（代行 C1）。**定位：19 期探索性估计，不是确认性实验。**
> 下文取代 v2 中与之冲突的全部内容。冻结集：`docs/work/evidence/T-007/t007_v3/`（v1、v2 保留作历史）。

### 1. 研究问题与可下的结论（G1 P0：识别与结论）
- 问题：在固定候选集合、数值信息、日期和推理配置下，向模型提供真实股票标识（相对随机匿名标识）是否改变其重排表现，改变多少。
- 主量 A−B = ρ_A − ρ_B（同一个 LGBM 基线被减掉，不受"基线很弱"的算术影响），只适用于 T-010 样本外分数的 Top-30 候选集合。
- **不做机制归因**：删去"因子推理 / 以记忆为主 / 部分记忆"。可下的表述只有"显式标识提供额外增益 / 降低表现 / 效应在 ±0.05 以内 / 未定"。
  A−B 为正不等于"记忆未来收益"（也可能是决策时点可得的公司知识）；A−B 不是记忆贡献，也不是其下界。负的 A−B 是有解释价值的结果，不是异常。
- 同时报告 A 与 B 的 Top-10 重合率与完整排序的一致性（平均表现相近不等于决策相同）。

### 2. 分组（G1 P0：对照与零点；P1：共同输出 schema、映射重复）
| 组 | 真实代码 | 七因子值 | LGBM 排名 / 候选顺序 |
|---|---|---|---|
| A | 提供 | 提供 | 与生产一致 |
| B | 未提供 | 提供 | 同 A |
| C* | 提供 | 未提供 | 同 A |
| D* | 未提供 | 未提供 | 同 A |
- 所有组用随机编号 S01–S30 作行 ID 与输出 ID，输出 schema 逐字相同（enum 按编号排序，不携带排名）；真实代码只是 A / C* 表里的一列，B / D* 该列写"未提供"。
- 共同的实验 system prompt：在生产 prompt 基础上改为"只根据本组实际提供的信息排序，未提供的列不惩罚"，保留"严禁基于训练数据中的股票历史知识做主观判断"。
  **与生产的差异**：system prompt 文字、行 ID 方案（生产直接用代码）；这是 2×2 设计所必需的，A 组因此不再逐字等于生产调用。
- 删去"C 是记忆上界""D 的 lift 应为 0"。C*/D* 是**保留 LGBM 信息的七因子消融**，不是空信息对照。
- 随机 Top-10 + LGBM 补尾的零分布不是 0：E[L] = −(1−λ)·ρ_LGBM，λ = (N−k)(N−k−1)/(N(N−1)) = 380/870（N=30、k=10）。
  分析里按期报告理论值与模拟值（不调用 LLM），只作描述，不作停止实验的门禁。
- 每个截面 5 个预先冻结的随机编号映射（同一重复内四组共用），截面内先对重复求平均；重复降低映射噪声，不增加独立时间样本。

### 3. 时间审计（G1 P0）
- 模型：Ternary-Bonsai-2-27B-PTQ1_0（GGUF sha256 53107f53…）；模型卡列出上游 Qwen/Qwen3.8-27B，**所查资料均未声明训练数据截止日**。
- 截止区间：保守 [2025-01-01, 2026-08-14]（下界来自 8 条本机探针，是弱证据；上界取上游公开发布日）；另报"若探针估计成立"[2025-01-01, 2025-03-31]。
- 每期记录决策日、收益基准日、收益结束日（第 63 个交易日）与暴露分类（`time_audit.csv`）：
  保守区间下 **11 期潜在完整暴露、8 期边界不确定、0 期截止后**；若探针估计成立，则 11 / 3 / 5。
  因此本实验**不能**声称任何一期是截止后预测；按暴露分类的 A−B 分组均值只作描述。
- 前瞻验证（冻结权重与流程、等待尚未发生的收益窗口）是另一项实验，不由本次匿名化替代。

### 4. 统计协议（G1 P0）
- 确认性比较族（4 个，Bonferroni）：A−B、B−D*、C*−D*、(A−B)−(C*−D*)。方向用 98.75% 双侧区间；等价用 TOST（97.5% 区间在 ±0.05 内）。
  **方向与等价分开记录**，可以同时成立（例如精确的 −0.01 既"显著为负"又"在 ±0.05 内"）；不再用互斥的有序判读矩阵。
- δ = 0.05 是事先设定的、针对本排序指标的容忍界限，**尚未与净投资收益建立对应关系**；不为得到等价结论而放宽。
- 区间：对每期配对差直接重采样；移动块自助法（不循环、块起点在 [0, T−L] 均匀抽、拼块后截断），百分位区间，10,000 次；
  主块长 2，敏感性 3、4、6，独立自助法作对照；同一块长下所有量使用同一组重采样索引；结论随块长改变 → 标"对依赖假设敏感"。
- 符号检验不再作为判读依据。
- 合法响应：schema 合法、编号在候选内且不重复、finish_reason=stop、思考为空。传输失败同一 run 内最多 3 次；模型输出不合法不重试；全部原始响应保留；
  已成功的请求永不重发（不允许重跑挑选）。配对单位 (截面, 重复)：四组都合法才算；截面至少 3 个合法重复才纳入；纳入 < 17 期 → 只报告工程失败。
- 锁定：GGUF sha256、llama.cpp build_info（b1-9a9394a）、聊天模板 sha256 写进 manifest，执行端不一致即拒绝运行；映射与排列种子在 manifest / 私有映射里。

### 5. 研究定位与功效（G1 P0）
- 本次是 19 期探索性估计。删去"约 90 个截面即可确认等价"的说法——那只是精度外推，不是功效论证
  （G1 的正态近似：在 v2 的精度假设下，90 期确认等价的概率约 16%，188 期约 80%）。

### 6. 附加（G1 P1，均为探索性）
- 描述性：各组绝对 IC；Top-30 内 LGBM 的 IC；相对同一 Top-30 等权收益的差；相对事先固定的简单因子规则（7 因子等权、符号取自生产 prompt）的 lift 差。
