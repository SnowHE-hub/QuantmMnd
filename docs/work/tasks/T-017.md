## 做法
1. `p2_build_v6.py` 增加可选参数（不给时行为与原来完全相同）：`--data-root`、`--prices-file`、`--calendar-file`、`--stock-basic`、`--panel-in/--panel-out/--sh-out`
   - `--calendar-file`：as_of 网格、标签 horizon、`read_lake_window` 的回看窗口统一用独立交易日历；价格表日期必须与日历**完全一致**，否则报错
   - 输出指向非默认路径时，已存在的文件一律拒绝覆盖；v5 文件任何情况下不可写
2. stock_basic：`docs/work/evidence/T-017/merge_stock_basic.py` 生成新文件 `data/lake/stock_basic_full_merged_20261009.parquet`
   （以 6 月的 15 列全表为底，用 T-015 刷新的列表更新 list_status / delist_date / name：12 只状态变化、11 只新退市、84 只改名；追加 28 只新股）。
   `name` 不参与任何因子计算（已检查 weekly_panel / pipeline / expansion）。
3. 产物（全部新文件，不覆盖 `alpha_panel_weekly_v6.parquet`、`short_horizon_factors_v6.parquet`）：
   `data/panel/alpha_panel_weekly_v6_1_base.parquet`（35 因子 + 12/21/63d 标签）→ `short_horizon_factors_v6_1.parquet` → 合并为 `alpha_panel_weekly_v6_1.parquet`
