# T-046 · X10 前视偏差诊断（第一版）：数值指纹扰动与闭卷对照

- 方案依据：03_final_plan_v2 第 10.4 节 X10。
  - 可用的手段：匿名化、改日期、闭卷对照、数值指纹扰动（把绝对金额乘一个统一的随机因子，比率不变）、在模型知识截止日之后的数据上重放；
  - **这些只能诊断，不能证明没有污染**；检测到污染就限制经济解释。
- 本卡先做数值指纹扰动和闭卷对照，对象是 A1（财务事实），评测集同 T-041（A1 留出集，40 个案例）。
- 分支：`t/035-line-a-v2-p0`，不推送。

## 登记（2026-10-23 16:xx，在运行之前）

### D1 数值指纹扰动
- 做法：A1 的工具结果里，所有单位是"元"或"万元"的金额都乘同一个因子 k = 1.37；比率、百分比、日期、股数不变。
  - 实现方式：在工具外面包一层，模型和校验器看到的都是扰动后的数据；
  - 其他与 T-041 的工具循环基线完全相同（DeepSeek flash、思考 high、提示词 v2）。
- 指标（只看有数值、单位是元或万元的 reported_fact 声明）：
  - 与扰动后的证据一致（相对误差 ≤ 0.5%）的比例：说明模型用的是工具数据；
  - 与**未扰动的真实值**一致、而与扰动值不一致的比例：说明模型从记忆里写了真实数字，记为"泄漏"；
  - 校验器的已核实占比、标准事实召回（标准事实同样乘 k），与 T-041 基线比较。
- 判定：泄漏比例 ≤ 1% 时，说 A1 的事实提取主要依赖工具数据；> 1% 就逐条列出，并在 A1 的使用说明里加上限制。

### D2 闭卷对照
- 做法：同一批 40 个案例，不给任何工具，只问模型：as_of 之前最近一个报告期的营业收入和归母净利润各是多少（元）。
  - 允许回答"不知道"；
  - DeepSeek flash，关闭思考，JSON 输出。
- 指标：
  - 回答了数字的比例；
  - 与真实值相对误差 ≤ 5% 的比例（"命中"）。
- 用途：只用来描述模型对这些公司历史财务数据的记忆程度。
  - 命中率高，说明涉及历史时点的研究结论，在经济解释上要打折扣；
  - 事实提取已经由 D1 和代码校验器控制。
