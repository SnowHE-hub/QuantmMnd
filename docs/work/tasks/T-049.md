# T-049 · X4 v2：公告分类改用学习得到的模型（语义蒸馏标签 + 盲标金标准）

- 用户 2026-10-23："我不想用标题规则……看看是不是模型训练方法有问题……除了计算外，不要搞这种卡死的硬规则"。
- 方案依据：03_final_plan_v2 第 9.1 节（公告和新闻分类：中文 MacBERT 监督分类器、VT 微调等候选）、第 10.4 节 X4。
- 分支：`t/035-line-a-v2-p0`，不推送。

## 诊断：X4 v1 的模型为什么没超过规则
1. **训练标签来自规则**：v1 的银标签要求"标题规则与结构化表或类别代码一致"（`x4_dataset`），所以模型学的就是规则本身。
   - MacBERT 在银标签测试集上 AUC 0.9993，微调 2B / 4B 是 0.9997 / 0.9998，都是"学会了规则"；
   - 规则在语义上的错误（例如限制性股票回购注销不算回购、"可能被实施"风险警示不算已实施、问询函回复不是收到问询函），模型照单全收；
   - 规则漏掉的说法，模型没有见过正例。
2. **难负例的构造也依赖规则**：标题含关键词、但规则判为别的类型的，被当作负例。其中有一部分其实是正例，模型被教成了拒绝这些写法。
3. **金标准 v1 的抽样分层也依赖规则**（pos_strong / pos_rule / uncertain / hard_neg），对规则比较有利。
- 所以要换的是**标签来源**，不是模型结构：训练标签必须按类别的语义定义来打，评测必须用不依赖规则的样本。

## 登记（2026-10-23 晚，在打任何标签、训练任何模型之前）

### 1. 训练与校准标签：DeepSeek 按语义定义蒸馏
- 样本（标题按模板去重，`x4_dataset.template`）：
  - 训练：2019-01-01 ～ 2023-06-30 约 30,000 条。一半按各类的宽松关键词分层（`TYPE_KEYWORDS`，每类约 1,000 条），一半全体均匀随机；
  - 校准：2023-07-01 ～ 2023-12-31 约 3,000 条，同样的抽法；
  - 种子 20261024。
- 标注：DeepSeek flash，关闭思考，结构化输出（T-048）。
  - 每次 20 条标题，给出 14 类的定义，每条返回它属于的类别（可以是多类或都不属于）；
  - 只发公开的公告标题和类别定义。
- 已知局限：标签来自另一个模型，有它自己的错误。所以要用独立的金标准评测，不能只看校准集。

### 2. 候选
| 候选 | 说明 |
|---|---|
| R 标题规则 | `ann_types.classify_title`，只作对照 |
| D DeepSeek 直接分类 | 与蒸馏用同一个提示（老师模型），每天约几千条标题，费用估算 < ¥5 / 天 |
| M MacBERT 多标签（本机） | hfl/chinese-macbert-base，只输入标题，14 个 sigmoid 输出；用蒸馏标签训练 3 个 epoch；每类阈值在校准集上按 F1 选 |

### 3. 金标准 v2（Claude 盲标）
- 测试期（2024-01-01 ～ 2026-10-16）的标题，排除金标准 v1 用过的公告，种子 20261024。两部分：
  - **A 关键词分层**：每类 30 条标题含该类宽松关键词的公告，问"是否属于该类"，共 420 个判断；
  - **B 均匀随机**：全体随机 200 条标题，每条标出它属于的全部类别（可以都不属于），用来估计关键词以外的漏判。
- **盲标**：Claude 只看类别定义和标题，看不到规则判断、DeepSeek 判断或模型分数；标完、提交之后才打分。
  - 标注原则沿用 T-038 的复核原则（写在那张卡里）；
  - 这是模型参考标签，不是人工金标准，结论里写明。

### 4. 指标与判定
- 在 A、B 合并的判断上，算每类与宏平均的精确率、召回率、F1，以及严重类型（与 v1 相同的 6 类）合并的召回率。
  - B 部分单独报"关键词以外"的召回。
- **采用条件**（取代 v1 的"规则保留"）：
  1. 候选的总体 F1 比规则高 0.05 以上；
  2. 严重类型召回率不低于规则。
- 满足条件的候选里，在 F1 与最好者相差 0.02 以内的，选最便宜的（M 本机 < D 调用）。
- 如果 M 和 D 都不满足：不回到规则了事。记录错误类型，改训练数据（例如补难例、扩大样本），在**新的金标准**上再测。
- 采用后，旁路事件监测和公告工具的类型字段改用选中的模型。规则保留为离线兜底（模型不可用时降级），并在报告里标明。

### 对照（指南 v1，不参与判定）

### 必须写明的局限

## X4 v2.1 登记（2026-10-24 01:3x，在难例标注和重训之前）
- 目的：模型在实盘数据上有两类典型错误（见上节），按用户要求从训练数据入手改进，不加标题规则。
- **难例池**：`scripts/line_a/x4_hard_examples.py`，输出 `data/line_a_v2/p4/x4_v21/hard_pool.parquet`。
  - 范围：2026 年 X4 年度表里 keep = True 的公告，随机抽 60,000 个不同标题（random_state 0）；
  - 排除金标准 v1 / v2 的公告编号，以及与金标准标题完全相同的公告；
  - 难例：模型的 14 类判断与标题规则（只算 14 类）不一致的标题。
- **切分**（种子 20261027）：
  - 从难例池随机抽 300 条，作为**难例验收集**（gold-hard），由 Claude 按指南 v2 盲标；标注之前不看任何模型对这些标题的判断；
  - 其余难例的 90% 作为训练补充，10% 并入校准集。
- **标注**：训练补充和校准补充由 DeepSeek 按指南 v2（与 v2 的训练集同一套提示词）标注。
  - DeepSeek 也对 gold-hard 直接分类，作为参照组 D；
  - D 的预测写进 `*_DO_NOT_OPEN_BEFORE_LABELS` 文件，Claude 标完之后才打开。
- **重训**：
  - 超参数与 v2 完全相同（lr 3e-5、3 轮、batch 64、max_len 64、种子 20261024）；
  - 训练集 = v2 训练集 + 训练补充；
  - 每类阈值在"v2 校准集 + 校准补充"上按 F1 选。
- **采用条件**（v2.1 替换 v2，三条都要满足）：
  1. gold-hard 上的 F1（14 类合并，按标题 × 类型计）比 v2 高 0.03 以上；
  2. 金标准 v2 上的 F1 不比 v2（0.967）低 0.005 以上；
  3. 金标准 v2 上的严重类型召回不低于 v2（0.946）。
  - 不满足就保留 v2，结果照样记录。
- 局限：
  - gold-hard 只包含"模型与规则不一致"的标题，衡量的是难例上的能力，不代表整体分布，整体分布由金标准 v2 衡量；
  - 标注者仍是模型（Claude、DeepSeek），不是人工。
