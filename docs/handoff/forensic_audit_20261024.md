## 四、重构方案与落地

### 后端：7 个聚合接口（`quantmind/line_a/api_analytics.py`）

所有接口都是只读的，价格面板按文件修改时间缓存。

| 接口 | 做什么 |
|---|---|
| `GET /api/forward/{d}?tickers=…\|source=formal\|f4\|f3top&horizons=1,5,10,20` | 事后收益，**一次请求返回整组**。口径如下：<ul><li>T+1 开盘、复权价入场，持有 h 个交易日，按第 h 日收盘计；</li><li>入场日停牌、开盘即涨停（涨跌停价用 `sim_account` 的规则，含 ST 7-06 切换）记为无法成交；</li><li>基准有四个：研究池（PIT 成交额前 1500）等权、沪深300、中证1000、中证2000；</li><li>超额 = 个股收益 − 基准收益；</li><li>没有到期的返回 null，不会拿"到今天为止"的收益来凑。</li></ul> |
| `GET /api/redteam/{d}?version=v1\|v2&horizon=` | 每只股票命中了哪些规则，以及事后表现。<ul><li>给出**标记组和未标记组**的绝对收益、相对研究池等权和中证2000 的超额；</li><li>给出跑输率、**基准跑输率**、两者之差，以及平均超额差；</li><li>分规则统计，样本不足 30 只时给出提示，缺少的规则输入如实列出；</li><li>v1 是原前端用的固定阈值；v2 改为当天截面前 10%（原因见第五节第 2 条）。</li></ul> |
| `GET /api/consensus/{d}?ticker=` | 四个模型和 ENS 在研究池里的截面百分位（0–100）。<ul><li>分歧度 = 四个百分位的标准差，另给极差；</li><li>给出这只股票的分歧度在全截面里的分位；</li><li>附上当天四个模型之间的 Spearman 相关矩阵。</li></ul> |
| `GET /api/claim/{d}/{ticker}/{ref}` | F7 一条声明的真实核验记录：<ul><li>原声明（含 formula、inputs、evidence）；</li><li>所引记录的字段原值和单位；</li><li>运行时的校验结论加上**用现在的校验器重跑**的结论，两者不同时会提示；</li><li>用 `verifier._eval` 按公式重算的结果；</li><li>运行文件名。</li></ul> |
| `GET /api/funnel/{d}` | 每一层当天的真实数量和明细。 |
| `GET /api/forward_ic?horizon=` | ENS 在每个运行日的事后 Rank IC（研究池范围）和前 10% 相对研究池的超额。 |
| `GET /api/rules/execution` | 执行规则：佣金、最低 5 元、过户费、印花税、各板块的最小申报单位和步长、各档设置。来源是 `formal.yaml` 和 `sim_account.py`。 |

其余后端改动：
- `/api/scores` 新增 `?ticker=` 参数，并返回全市场排名 `rank`；
- `/api/dates` 新增 `brain` 和 `claims` 两个日期列表；
- 产物缺失时返回 404，不再返回 500；
- CORS 只允许本机 5173 访问。

## 五、改完之后看到的真实结果（10 个运行日，样本很少，只作跟踪）

1. **ENS 20 日模型的事后 5 日 Rank IC**：已到期的 5 个运行日（10-12 到 10-16）分别为 −0.21、−0.20、+0.19、−0.05、+0.17，平均 −0.02；前 10% 相对研究池平均 −1.2%。
   - 研究期的日均 RankIC 是 0.145（T-030）；
   - 5 天的前瞻值波动很大，持有期又互相重叠，现在下不了结论，但值得持续盯着。
2. **红队规则没有显示出信息量**。
   - v1 的固定阈值（beta > 2.5、波动 > 70%）在 10-23 的研究候选里标记了 85%（10-14 是 100%）。原因是 ENS 选出来的本来就是高波动小盘股，这套阈值几乎没有区分度。
   - v2 在 10-14 标记了 92%，主要是那天的事件监测把大量股票标成了重大事件。
   - 结果：标记组只有 56% 跑输研究池等权，**未标记组是 75%，标记组反而更好**。
   - 结论：红队标记目前只能作为提示，不能当成排雷依据。这和 T-056 的做法一致：大脑的标记要积累 60 条、40 个交易日之后再做前瞻判定。
3. **10-12、10-13 这两天的运行没有 bypass 和风险卡**（当时流水线还没有这两步）。现在接口会把缺少的输入如实标出来，而不是显示"没有风险"。
